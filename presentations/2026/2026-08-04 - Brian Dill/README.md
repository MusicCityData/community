# DuckDB 101 - Zero to 500 Million in Less Than a Second

* **Speaker:** Brian Dill
* **Date:** 2026-08-04
* **Meeting:** Music City Data User Group — [event on Meetup](https://www.meetup.com/music-city-data-user-group/events/315818054)

## Abstract

Learn how to setup and use THE best tool there is for exploratory data analysis. Brian
will present demos using both the built-in UI notebooks as well as the free-to-use
DBeaver. Learn about when and why to use DuckDB by learning what it is VERY good at, and
what it doesn't do so well.

**Level:** Basic SQL knowledge expected.

## Speaker

Brian has lived in the Nashville area for 30 years. He was a .NET developer in a past
life and is a longtime SQL Server DBA who has recently pivoted towards data engineering.
He enjoys automating with PowerShell, creating visualizations in R, doing "stuff" with
Python, and loves data and SQL databases—SQL Server, PostgreSQL, MySQL/MariaDB, SQLite,
and of course DuckDB!
