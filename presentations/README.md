## How Materials Are Organized

When we host a deck here, it goes in a folder grouped by year:

```
<year>/<YYYY-MM-DD> - <Speaker Name>/
```

Each folder holds the slides (PDF preferred), any demo/sample code, and a short README.
See [`_template/`](_template/) for a starter.

## Adding a Presentation

* **You host your own slides:** email the link to
  [speakers@musiccitydata.org](mailto:speakers@musiccitydata.org) (or open a PR editing
  the table above) and we'll add it to the index.
* **You'd like us to host them:** add a `<year>/<date> - <name>/` folder with your files
  and a short README, then open a pull request — or email the files to
  [speakers@musiccitydata.org](mailto:speakers@musiccitydata.org) and an organizer will
  add them.

Only upload materials you have the right to share. You retain copyright unless you state
otherwise.
